# Reviewer 3 冻结报告

评审对象为 manuscript_CBM_submission.pdf 全文8页。重点为应用意义、跨学科可读性与复现，同时覆盖五个评估轴。仅依据该PDF及本地评审规则，未查阅项目代码、其他报告或网络资料。五轴用于组织评审，不将 Nature 的选稿门槛当作 CMPB 官方标准。本报告在提交后冻结。

## 总体判断、读者与优点

建议大修。问题具有明确的生物医学计算意义，利用生理延迟先验改善小样本跨被试多模态分类，适合关注混合BCI、神经工程和生理约束机器学习的读者。主体结果提供了有价值的架构性能证据，但当前稿件把架构比较、机制解释和部署能力连接得过紧。

优点包括按被试划分训练、验证和测试集合，以被试为统计单位，报告多随机种子、传统分类器及独立任务数据集结果，并区分观测窗口与GPU前向计算成本。主数据集完整模型79.37%的准确率，以及跨种子78.22%的均值，值得进一步核验和清晰呈现。

## Major Concerns

### R3-M1 生理机制的因子分解混入了架构变化

- Severity Major；Blocking Yes；主要轴为技术可靠性与原创性。
- Claim pointer 为第6页5.2节、第8页6.2节和结论。稿件称完成P与M的完整2×2分解，并将7.70 pp增益归于两个时间先验。
- Evidence pointer 为第6页表2及表注。Poff/Moff行明确采用没有浅层分支的Standard Attention，而Pon/Mon行采用完整架构79.37%；同表真正的Latent-Only为77.76%。正文又称因子矩阵在deep attention stream内进行。
- 问题是四个格子没有被证明仅改变P和M。至少两个角点还改变浅层分支与融合路径，因此7.70 pp并非两个时间先验的可识别效果。这直接影响论文的核心机制结论。
- 解决标准为提供架构、训练方案与预处理一致、仅切换P和M的四格结果，明确另外两格的分支配置，并报告适当的配对效应。若不补此分析，应将现有结果作为不同架构比较，删除独立归因于P与M的效应量。

### R3-M2 核心输入特征和时间标记缺乏一致的可复现定义

- Severity Major；Blocking Yes；主要轴为技术可靠性和可读性。
- Claim pointer 为第2页方法概述、第3页图1和3.5节，对所评估架构及直接生理摘要的定义。
- Evidence pointer 为图1的全窗口EEG平方均值对数与全窗口fNIRS均值，对照式(8)及第4页续文的4–30 Hz功率、延迟均值加0.5倍斜率；第3页3.3节的对称卷积填充与式(5)的严格物理时间戳；第8页代码声明仅称MIT license on Zenodo，无记录链接或版本。
- 图示和公式给出不同的浅层输入，因而独立实现者不能确定哪些特征产生了主结果。另需解释卷积及池化后的token时间戳如何对应原始采样点和感受野。对称卷积可将名义时间点之后的样本编码进token，故token索引上的掩码不自动保证原始信号层面的严格因果性。代码获取声明目前不能帮助消除这些不确定性。
- 解决标准为统一图示、公式与实际评估模型，精确定义功率汇总、斜率归一化、时间窗口及token时间映射，区分token配对约束与输入处理因果性；给出可定位的代码版本或完整实现说明。若核验发现结果对应另一版本，应同步更新受影响结果。

### R3-M3 无校准和实时应用的表述超出了目前的评价协议

- Severity Major；Blocking No；主要轴为科学意义、跨学科读者与技术可靠性。
- Claim pointer 为摘要结论及第8页6.3节的calibration-free和real-time compliance，另见第7页5.5节对闭环延迟的判断。
- Evidence pointer 为第4页4.1节，EA使用各被试未标记试次估计参考协方差；第2页3.1节，光学参考采用连续session均值；第5页4.4节，只测量GPU驻留张量的前向调用；第6至7页5.5节明确采用离线截短。
- 无目标标签的跨被试评价有价值，但目标被试数据参与EA，与新被试首个试次即可直接预测是不同的使用条件。GPU前向时间和离线截短结果也未计入预处理、数据传输、目标被试参考估计及完整采集流程。临床或工程读者需要知道实际何时能得到第一项决定。
- 解决标准为明确目标被试无标签数据的数量、取得时点和参考估计流程，将当前结果准确界定为使用无监督目标被试对齐的离线LOSO及设备驻留前向成本。若保留在线部署结论，应提供只使用当时已获得数据的处理协议与端到端时延评价。无需为保留离线方法贡献强制开展临床试验。

### R3-M4 第二数据集验证的是重新训练后的方法适用性，模态互补解释仍缺关键对照

- Severity Major；Blocking No；主要轴为科学意义和跨学科读者。
- Claim pointer 为第8页6.3节的cross-cohort generalizability、结论的跨任务泛化，以及第7页5.6节的互补神经血管信息解释。
- Evidence pointer 为第4页4.2节，第二数据集独立执行26折LOSO；第7页表5列有完整模型、两种混合传统分类器、深浅分支与EEGNet，但未列fNIRS-only。完整模型62.95%，LDA64.29%，两者p=0.3985。
- 在第二数据集重新训练可支持架构跨任务应用，不能直接表示一个已训练模型跨队列迁移。第二数据集EEG接近机会水平时，与EEG相比的14.62 pp优势也不能单独说明EEG为fNIRS贡献了互补信息。现有结果完全可能由光学输入贡献主要判别能力。
- 解决标准为直接写明第二数据集独立训练和评估的范围；加入同协议fNIRS-only对照以检验混合输入的额外收益，或将该部分结论收束为完整架构在第二任务上的分类表现。讨论应解释为何第二任务中复杂模型与传统混合分类器表现相近，以便读者判断方法的适用条件。

## Minor Comments

### R3-m1 验证划分与种子表述需给出可执行规则

- Severity Minor；Blocking No；轴为复现。
- Affected element 为第4页4.1节与第5页表1表注。
- Evidence pointer 为“five participants”之后只给出单个循环索引(s−1) mod 28，以及42+s与Seed 42的并列使用。
- 修正要求为给出五位验证被试的明确生成规则，并说明42、100、2024是基础种子还是实际折种子。发布被试划分表即可直接消除歧义。

### R3-m2 比较模型的命名应保持实现层级一致

- Severity Minor；Blocking No；轴为原创性与可读性。
- Affected element 为第4页4.2节、第5页表1和5.1节。
- Evidence pointer 为方法称shared-encoder controls，结果却称recent multimodal deep learning architectures，并以引用论文模型名称标注Feature-Concat与Standard-Attention。
- 修正要求为明确哪些是共享骨干的受控实现，哪些是按原论文重现的完整模型。表格沿用能反映实际实现的名称，并简述与所引工作的关系，避免读者将受控融合比较理解为全面复现已有方法。

### R3-m3 诊断图的统计单位和向量汇总需要标明

- Severity Minor；Blocking No；轴为可读性与复现。
- Affected element 为第7页图3a、3c与第6页5.3节。
- Evidence pointer 为A具有多头、被试和试次层级，而图3a只展示一个矩阵；式(9)的gb为64维向量，图3c却展示标量门值分布。
- 修正要求为说明图3a的被试、试次、类别、注意头及汇总方式，图3c如何先后汇总64个维度、试次和被试。门值均值体现融合权重，不能单独作为跨任务神经血管协调机制的证据。

## 五轴与建议

| 评估轴 | 判断 |
|---|---|
| 原创性 | 生理延迟先验与门控结构的组合有方法学价值，但因子分解和比较实现的界定决定能够主张多大程度的独立贡献。 |
| 科学意义 | 主数据集有可量化的离线性能优势；第二任务接近传统混合分类器，适用条件比普遍优越性更值得解释。 |
| 跨学科读者兴趣 | 混合BCI、神经工程及生理约束学习研究者会关注；准确区分无标签适配、独立任务再训练和直接部署可提高临床工程读者的理解。 |
| 技术可靠性 | 主体LOSO设计和被试层级报告有基础；R3-M1与R3-M2必须解决，才能建立核心机制和可复现架构的结论。 |
| 非专科可读性 | 问题背景清楚，流程图有帮助；图文特征冲突、因果性措辞和多种“泛化”的混用目前改变了读者对证据的理解。 |

建议在完成上述关键修订后重新评价。CMPB相关性是积极的，当前证据最有说服力的定位是生理先验辅助的跨被试离线分类方法。未核验原始预测、代码实现和参考文献全文，因而不对其真实性或准确性作超出PDF的推断。
