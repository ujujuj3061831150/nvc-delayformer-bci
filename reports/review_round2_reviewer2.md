# Reviewer 2 冻结报告

审阅范围为 manuscript_CBM_submission.pdf 全文8页。只依据该PDF及 nature-reviewer 本地评审依据，未查阅项目代码、其他评审或外部文献。以CMPB的生物医学计算方法读者为目标，五轴用于组织评价，不将Nature的广泛影响力门槛当作CMPB要求。本报告提交后冻结。

## 总体评价与优点

将血流动力学延迟写入跨模态注意力，是清楚且有应用价值的方法设计。29人LOSO、共享编码器对照、传统分类器、多随机种子、输入扰动及计算成本报告构成了较完整的评估框架。主数据集中78.22%的三种子均值，以及相对LDA的6.55个百分点主运行增益，值得混合BCI、生理信号融合和小样本跨受试者学习读者关注。

当前证据较有力地支持完整架构的离线分类效果，但对增益来自生理时延对齐的归因，以及跨队列泛化和无需校准的表述支持不足。建议大修，先解决可比性与方法定义，再评估创新力度。

## Major Concerns

### R2-M1 因子设计混入浅层支路变化

- **Severity** Major。**Blocking** Yes。**Axis** 技术可靠性、原创性归因。
- **Claim pointer** 第6页§5.2及第8页结论将完整模型相对无约束注意力的7.70个百分点增益归于Gaussian prior和causal mask的2×2分解。
- **Evidence pointer** 第6页表2及表注明确指出Poff/Moff为不含浅层支路的44,626参数深层模型；Pon/Mon则为完整模型。另有保留先验但去掉浅层支路的Latent-Only，准确率77.76%，低于完整模型79.37%。
- **Concern** 两个因子之外的融合支路也发生变化，因此这不是保持其他结构不变的完整2×2比较。7.70个百分点同时包含先验和架构变化，不能作为时延机制的独立贡献。
- **Resolution test** 在同一深层或同一完整架构上重做四格比较，明确各格参数、浅层支路和门控状态，并报告配对效应。或者撤销因子归因，将现有结果明确界定为架构级比较；如继续声称两个因子的协同作用，应提供相应交互证据。

### R2-M2 生理对齐的解释超出诊断实验所区分的机制

- **Severity** Major。**Blocking** Yes。**Axis** 科学重要性、机制证据。
- **Claim pointer** 第1页摘要结论和第8页结论称解决了两种模态的时间尺度差异；第6页§5.3用注意力脊线及门控均值确认生理约束与协调神经血管整合。
- **Evidence pointer** 式(6)直接把约5秒脊线和零权重区域写入注意力；§5.3固定权重扫描中准确率从5秒的79.48%升至8秒的80.46%；表3中5秒循环移位仅降低0.98个百分点，类内换配降低2.24个百分点；式(9)同时混合经过学习投影的两个潜在向量。
- **Concern** 强制生成的脊线主要验证约束实现，门控均值也不直接量化生理贡献。现有扰动提示类别信息和频谱信息重要，但尚未区分真实试次时序对齐与一般的注意力正则化。该区别直接决定本研究是有效的工程先验，还是对神经血管时间对齐提出了新的科学解释。
- **Resolution test** 优先将结论落在“生理启发的时序约束改善完整架构的跨受试者分类”。若保留生理对齐机制主张，需在结构匹配条件下加入可区分一般平滑/局部注意力约束与生理延迟约束的对照，并报告折间学习延迟及对试次配对的依赖；不能以被预先规定的热图形状作为独立机制验证。

### R2-M3 第二数据集证明的是独立任务内LOSO表现

- **Severity** Major。**Blocking** No。**Axis** 科学重要性、泛化范围。
- **Claim pointer** 第8页§6.3称第二队列确认“cross-cohort generalizability”，结论称跨不同认知任务的泛化；第7页§5.6将结果解释为多模态互补整合。
- **Evidence pointer** 第4页§4.2在第二数据集重新采用21人训练、4人验证、1人测试的26折LOSO。第7页表5完整模型62.95%，LDA为64.29%，二者p=0.3985；表中无fNIRS单模态对照。
- **Concern** 此设计支持方法在另一任务上重新训练后的适用性，未检验从第一队列训练后直接迁移的效果。相对近随机EEGNet的14.62个百分点优势，也无法区分新增光学信息的贡献和融合机制本身的价值。第二队列的科学意义应结合强传统基线表现解释。
- **Resolution test** 将表述统一为第二数据集内独立LOSO验证；若保留跨队列迁移表述，补充相应训练与测试设计。增加匹配的fNIRS单模态对照以支持互补性，并在摘要或主要讨论中直接报告与LDA相当的结果。

### R2-M4 新方法与已有模型的距离尚未清楚建立

- **Severity** Major。**Blocking** No。**Axis** 原创性。
- **Claim pointer** 第2页Related Work及第5页§5.1将结果定位为优于已有多模态深度学习架构。
- **Evidence pointer** §4.2说明Feature-Concat及Standard-Attention为共享编码器控制；表1却使用“Multi-View Hybrid CNN”和“Cross-Modal Transformer”及文献[11–13]命名。Related Work主要描述通用注意力、EEG单模态网络和生理依据，未具体比较这些最近邻融合方法的时序处理、门控和训练设置。
- **Concern** 共享编码器实验适合回答本研究内部的结构问题，但读者无法据此判断引用模型是否被忠实复现，也难判断新颖性主要落在先验参数化、门控组合还是既有模块集成。这里不能从缺少外部核验进一步推定已有工作已实现相同方法。
- **Resolution test** 将内部控制与文献模型复现清晰区分，说明对引用方法保留和改变了什么，并逐项交代最接近工作的差异。对论文级优越性主张，提供对应可比实验；否则以共享编码器控制的结果来界定贡献。

### R2-M5 核心特征分支存在互不相同的定义

- **Severity** Major。**Blocking** Yes。**Axis** 可重复性、技术可靠性。
- **Claim pointer** 第3页图1及§3.5定义实际参与完整模型和Direct-Only比较的生物物理摘要特征。
- **Evidence pointer** 图1给出全时窗EEG平方均值取对数和光学全时窗均值；式(8)及第4页说明给出DFT提取4–30 Hz功率，以及延迟光学均值加0.5倍斜率。第4页还增加图1未表达的EEG通道门控。第8页代码声明仅写MIT许可的Zenodo包，没有可定位标识符。
- **Concern** 两种浅层输入并不等价，影响特征解释、截窗实验和分支消融。仅凭PDF不能确定表中性能对应哪个方法，也不能复现核心架构。
- **Resolution test** 按实际生成表格的实验统一图、公式和文本，给出频带功率、光学斜率归一化及时间窗的完整定义，明确门控位置，并提供可定位、版本固定的代码归档与结果配置。修正后核对参数量和关键结果是否仍对应最终方法。

### R2-M6 “无需校准”和严格物理因果的运行条件未被验证

- **Severity** Major。**Blocking** No。**Axis** 应用重要性、技术范围。
- **Claim pointer** 第1页摘要和第8页讨论、结论宣称calibration-free及real-time compliance；引言称mask防止future-information leakage。
- **Evidence pointer** §4.1的EA使用每个测试参与者未标注试次估计协方差；§3.1光学转换使用连续整段会话均值；§3.3明确采用对称padding卷积；§4.4只计设备驻留张量的前向耗时。
- **Concern** 当前评估包含目标受试者批量无监督适配。token间掩码约束也不等于每个token的感受野或完整预处理满足严格时间因果。2.22 ms是有用的模型执行指标，但尚不能单独建立从首次观测开始、无需目标受试者统计量的在线运行结论。
- **Resolution test** 明确将当前条件表述为无需目标标签、采用批量无监督对齐的离线LOSO；把因果措辞限定到token注意力约束，保留精确的GPU前向时延。若维持在线与严格因果主张，应给出只利用当时可用数据的预处理、逐步EA和完整感受野/时延验证。

## Minor Comments

### R2-m1 外部队列统计说明

- **Severity** Minor。**Blocking** No。**Axis** 可读性、统计报告。
- **Claim pointer / Evidence pointer** 第4页§4.3统一写置信区间自由度28，但第7页表5包含26人队列。
- **Required correction** 分别写明两队列的自由度、外部队列多重比较家族及多种子配对单位，确保统计方法可以直接对应各表。

### R2-m2 “双分类读出”与架构不符

- **Severity** Minor。**Blocking** No。**Axis** 非专门读者可读性。
- **Claim pointer / Evidence pointer** 第2页Methods首段称“dual classification readouts”，图1和式(9)展示两个特征分支融合后接一个分类头。
- **Required correction** 若实际为单分类头，将其改为双表征分支；若存在额外读出，给出其训练损失和推理用途。

## 五轴判断与建议

| 评价轴 | 判断 |
|---|---|
| 原创性 | 生理延迟先验有明确设计特色，独立贡献尚受混杂消融与最近邻方法定位不足影响。 |
| 科学重要性 | 主队列的分类提升具有领域内方法价值；现有材料支持工程性能改善，对生理对齐机制的解释仍需收紧。 |
| 跨领域读者兴趣 | 适合混合BCI、生物医学信号处理及多模态学习读者；尚无临床效用或跨队列直接迁移证据。 |
| 技术可靠性 | 受试者级划分、统计和多种子是优点；R2-M1、R2-M2、R2-M5须先解决，才能成立当前核心论证。 |
| 非专门读者可读性 | 问题与流程总体易理解，但架构定义及“外部泛化、因果、无需校准”等术语应与实际协议一致。 |

**建议立场** 大修后重新评估。主要价值应首先建立在可复现、结构匹配的跨受试者计算方法上，无需用尚未检验的生理机制或部署结论增强说服力。
